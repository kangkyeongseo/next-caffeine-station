# <span id='top'>Caffeine Station</span>

## ☕️ 서비스 소개 (근처에 내가 원하는 카페는?)

카페에서 지인들과 커피를 마시면서 얘기를 나누고 싶을 때는 유명 가맹점에서 편하게 즐기고 싶고 </br>
지친 몸에 카페인만을 원할 때는 가성비 좋은 가맹점을 찾는 경우가 있습니다.</br>
그럴 때마다 주위에 해당 가맹점을 지도 앱에서 일일이 찾아보는게 불편하여 제작하였습니다.

> 배포 주소 : <a href='https://caffeine-station.vercel.app/'>Caffeine Station </a>

## 🗺 주요 기능

### 필터 검색

- 거리 및 브랜드 타입 필터 검색
- 카카오 지도의 커스텀 오버레이 생성 및 조건부 변경
